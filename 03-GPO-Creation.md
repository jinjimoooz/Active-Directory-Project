## Group Policy Objects (GPO) Configuration

**Applied Password Policy:**

- Minimum password length
- Password complexity requirements
- Minimum and maximum password age

**Applied Account Lockout Policy:**

- Account lockout threshold
- Account lockout duration
- Reset account lockout counter

**Drive Mapping:** Configured Group Policy Preferences (GPP) to map network shared drives automatically.

**Desktop Wallpaper Policy:**

- Enforced a standardized corporate desktop background.

**Access Restrictions:**

- Prohibited user access to the Control Panel and Windows Settings.

**Removable Storage Devices:**

- Disabled read/write access to USB storage devices.
